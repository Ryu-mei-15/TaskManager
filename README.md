# Progress Hub

ゼミのタスク管理、進捗確認、Scrapbox向け進捗レポート作成を1つにまとめたブラウザアプリです。

サーバーやアカウント登録を必要とせず、HTML・CSS・JavaScriptだけで動作します。登録したタスクやレポートの下書きは、利用中のブラウザ内に保存されます。

## 最初に知っておいてほしいこと

> [!IMPORTANT]
> タスクは端末間で自動共有されません。

このアプリには、クラウド同期、ログイン、共有データベースの機能がありません。データはブラウザの `localStorage` に保存されるため、次の環境はそれぞれ別のデータを持ちます。

- 別のPCやスマートフォン
- ChromeとSafariなど、異なるブラウザ
- 同じブラウザの異なるユーザープロファイル
- 通常ウィンドウとシークレット／プライベートウィンドウ
- GitHub Pages、`localhost`、別ポートなど、URLの配信元が異なる環境

同じ公開URLを別端末で開いても、タスクは自動では表示されません。別端末へ移す場合は、アプリの「設定」からJSONバックアップを書き出し、移行先で復元してください。

## 主な機能

- 未着手・進行中・完了によるタスク管理
- 期限、時刻、重要度、タグ、メモ、サブタスクの設定
- リスト表示とドラッグ＆ドロップ対応のカンバン表示
- タスク名、メモ、タグを対象にした検索と絞り込み
- 進捗率の記録
- 期限の近いタスクや重要タスクの強調表示
- 完了履歴と直近7日・30日の集計
- Scrapbox形式の進捗レポート生成
- レポート下書きの自動保存
- ブラウザ通知による期限アラート
- JSONによるバックアップと復元
- PC・タブレット・スマートフォン対応

## 使い始める

### 公開済みのページを利用する場合

管理者から案内されたURLをブラウザで開いてください。インストールやログインは不要です。

初回利用時はデータが空の状態です。ほかの端末で利用していたデータがある場合は、先に「設定」→「復元する」からバックアップを読み込んでください。

### ローカルで起動する場合

このリポジトリを取得し、ディレクトリ内で静的Webサーバーを起動します。

```bash
git clone https://github.com/Ryu-mei-15/Task-Manager.git
cd Task-Manager
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。

`index.html` を直接開いても基本機能は利用できますが、通知機能やブラウザの保存仕様が環境によって異なるため、`localhost` またはHTTPSでの利用を推奨します。

## 基本的な使い方

### 1. タスクを追加する

「タスク」画面上部の入力欄にタスク名を入力し、「追加する」を押します。

「期限・タグ・メモも設定する」を開くと、追加時に次の情報も設定できます。

- 期限日と時刻
- 開始状態
- メモや完了条件
- タグ
- 最優先設定

キーボードの `N` を押すと、新規タスク入力欄へ移動できます。入力欄へ文字を入力した状態で `Enter` を押しても追加できます。

### 2. タスクを更新する

タスクカードでは、進捗スライダー、完了操作、サブタスク追加が利用できます。「編集」からは、すべての項目をまとめて変更できます。

タスクの背景色は次の意味です。

| 表示 | 意味 |
| --- | --- |
| 赤 | 期限超過 |
| オレンジ | 期限まで24時間以内 |
| 黄 | 期限まで1週間以内 |
| 青 | 重要タスク |

期限警告は重要表示より優先されます。ホーム画面の「近い予定」では、重要タスクに `★ 重要` が表示されます。

### 3. タスクを探す

検索欄では、タスク名だけでなくメモやタグも検索対象になります。ステータス、タグ、期限、更新日時で絞り込み・並べ替えもできます。

キーボードの `/` を押すと、検索欄へ移動できます。

### 4. カンバンを使う

「タスク」画面右側の表示切り替えで「ボード」を選ぶと、未着手・進行中・最近の完了を一覧できます。カードを別の列へドラッグすると、ステータスも変更されます。

### 5. 進捗レポートを作る

「進捗レポート」画面で作業内容を入力すると、右側にScrapbox形式の文章がリアルタイム生成されます。

- 指定期間内に完了したタスクは「実際にやったこと」へ自動追加されます。
- 未完了タスクは「次回までにやること」へ自動追加されます。
- 空欄の任意項目は出力から省略されます。
- 必須項目に情報がない場合は「要確認」と表示されます。
- 入力内容はブラウザ内へ自動保存されます。

内容を確認したら「コピーする」を押し、Scrapboxへ貼り付けてください。

## データはどこに保存されるか

アプリは次のデータをブラウザの `localStorage` に保存します。

| データ | 保存キー |
| --- | --- |
| タスク | `tasks_v10` |
| 表示設定 | `progress_hub_preferences_v11` |
| レポート下書き | `progress_hub_report_draft_v11` |

保存先はGitHubリポジトリではありません。タスクを追加しても、`app.js` や `index.html` が書き換わったり、GitHubへ送信されたりすることはありません。

また、アプリのソースコードを更新しても、同じURL・同じブラウザの保存領域を使っている限り、通常は既存データが引き継がれます。ただし、ブラウザデータの消去や保存領域の変更が起きると復元できないため、バックアップを推奨します。

### データが失われる可能性がある操作

- ブラウザのサイトデータを削除する（通常、キャッシュだけの削除では消えません）
- シークレット／プライベートウィンドウを閉じる
- 別のURL、ドメイン、ポートからアプリを開く
- ブラウザや端末を初期化する
- アプリの「すべてのタスクを削除」を実行する
- ストレージを自動削除するブラウザ設定や端末設定を利用する

重要なタスクを登録したら、定期的にJSONを書き出してください。

## 端末間でデータを移す

### 移行元の端末

1. 「設定」を開く
2. 「バックアップ」の「書き出す」を押す
3. `progress_hub_backup_YYYY-MM-DD.json` が保存されたことを確認する
4. AirDrop、クラウドストレージ、USBなど、信頼できる方法で移行先へ渡す

### 移行先の端末

1. 同じアプリを開く
2. 「設定」を開く
3. 「復元する」を押す
4. 移行元で書き出したJSONを選ぶ
5. 件数を確認し、置き換えを承認する

バックアップには、タスク、サブタスク、レポート下書き、表示設定が含まれます。

> [!WARNING]
> 復元は現在のタスクを置き換えます。2台のデータを自動で統合する機能はありません。

## 複数端末で安全に使うための運用例

複数端末を行き来する場合は、次の運用をおすすめします。

1. 主に編集する端末を1台決める
2. 別端末へ移る直前に、編集元から最新バックアップを書き出す
3. 移行先に既存データがある場合は、念のため移行先側も先に書き出す
4. 最新バックアップを移行先で復元する
5. 古い端末で同時編集しない
6. 日付入りバックアップを数世代残す

2台で別々にタスクを編集したあと、一方のバックアップをもう一方へ復元すると、復元先だけに存在した変更は失われます。

リアルタイム同期や複数人での共有が必要な場合は、現在の実装にバックエンド、ユーザー認証、同期処理を追加する必要があります。

## プライバシーと安全性

- 通常のタスク操作だけで、データが外部サーバーへ送信されることはありません。
- バックアップJSONには、タスク名、メモ、URL、レポート内容などが平文で含まれます。
- 機密情報を含むバックアップは、公開リポジトリや誰でも閲覧できる場所へ置かないでください。
- 共用PCで利用する場合は、ほかの利用者が同じブラウザプロファイルを開ける可能性を考慮してください。
- 「すべてのタスクを削除」は元に戻せません。実行前にバックアップしてください。

## 通知機能について

通知を許可すると、期限まで24時間以内になったタスクをブラウザ通知で知らせます。

次の制限があります。

- アプリを開いている間だけ期限チェックが動作します。
- OSとブラウザの両方で通知が許可されている必要があります。
- 通知を一度拒否した場合は、ブラウザのサイト設定から許可し直す必要があります。
- ブラウザによっては、HTTPSまたは `localhost` でのみ通知を利用できます。
- 通知は端末ごとに設定します。

## 困ったとき

### 別端末でタスクが表示されない

仕様どおりです。移行元からJSONを書き出し、移行先で復元してください。

### 前に登録したタスクが見つからない

次を確認してください。

1. 前回と同じ端末か
2. 前回と同じブラウザ・プロファイルか
3. 前回と同じURLか
4. シークレット／プライベートモードではないか
5. 検索やタグ・ステータスの絞り込みが残っていないか

### 復元できない

このアプリから書き出した `.json` ファイルを選んでいるか確認してください。ファイルを手動編集した場合、JSONの形式が壊れている可能性があります。

復元前のデータを残したい場合は、先に現在の端末からもバックアップを書き出してください。

### 通知が来ない

ブラウザのサイト設定とOSの通知設定を確認し、アプリを開いた状態にしてください。「設定」画面の通知ボタンからテスト通知を送れます。

## 開発者向け情報

### 構成

```text
Task-Manager/
├── index.html   # 画面構造
├── styles.css   # デザインとレスポンシブ対応
├── app.js       # タスク管理、保存、レポート生成
├── favicon.svg  # ファビコン
└── README.md
```

ビルド工程や外部ライブラリはありません。静的ファイルを配信できる環境で動作します。

### 変更時の注意

- `tasks_v10` を変更する場合は、既存データの移行処理を用意してください。
- バックアップ形式を変更する場合は、以前のJSONも読み込めるよう互換性を保ってください。
- ユーザー入力をHTMLへ表示する場合は、`escapeHtml()` を通してください。
- 端末間同期を追加する場合は、競合解決、認証、アクセス制御、データ暗号化も設計してください。

### 簡易チェック

```bash
node --check app.js
git diff --check
```

## 現在対応していないこと

- 端末間の自動同期
- 複数人でのリアルタイム共同編集
- アカウント・ログイン
- サーバー側バックアップ
- JSON復元時のデータ統合

これらが必要な場合は、クラウド保存機能を追加する必要があります。
